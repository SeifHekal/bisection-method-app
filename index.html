Numerical Methods Handbook • Core Formulas

Bisection Method (Interval Halving)

Foundation: Grounded in Bolzano's Intermediate Value Theorem. If a real-valued continuous function satisfies f(a) · f(b) < 0, there exists at least one real root r ∈ [a, b].

Midpoint Iteration Formula
ck = (ak + bk) / 2

Interval Contraction Rule:

  • If f(a) · f(c) < 0, the root lies in the lower half: set b = c.
  • Else if f(b) · f(c) < 0, the root lies in the upper half: set a = c.
  • If f(c) = 0, the exact root is found.
Convergence Guarantee: Guaranteed global convergence at a linear rate (order p = 1.0). Each iteration cuts the bracket uncertainty by exactly 50%: Δxk+1 = ½ Δxk. The maximum error after k steps is bound by (b − a) / 2k.

Secant Method (Linear Interpolation)

Eliminates the derivative requirement of Newton-Raphson by approximating the tangent slope with a finite-difference secant chord between two successive estimates xn−1 and xn.

Secant Iteration Formula
xn+1 = xn − f(xn) · [ (xn − xn−1) / (f(xn) − f(xn−1)) ]
Convergence Rate: Superlinear convergence order p = (1 + √5) / 2 ≈ 1.618 (the Golden Ratio). Converges significantly faster than Bisection without evaluating derivatives.

Newton-Raphson Method (Tangent Line)

Constructs the tangent line at (xn, f(xn)) with first derivative slope f'(xn) and follows it to its x-axis intercept to produce the next approximation.

Newton-Raphson Iteration Formula
xn+1 = xn − [ f(xn) / f'(xn) ]

In this application, numerical derivatives f'(x) are evaluated using centered finite differences with high precision:

Central Difference Derivative
f'(x) ≈ [ f(x + h) − f(x − h) ] / (2h),   where h = 10−7
Convergence Rate: Quadratic order (p = 2.0). The number of correct decimal places doubles every single iteration near simple roots.

Fixed-Point Iteration (x = g(x))

Transforms the non-linear equation f(x) = 0 into the equivalent fixed-point relation x = g(x), producing successive approximations through recursive evaluation xk+1 = g(xk).

Successive Substitution Formula
xk+1 = g(xk)

Convergence Condition & Cobweb Geometry:

  • Contraction Mapping Theorem: Convergence to fixed point x* is guaranteed if |g'(x)| < 1 in an interval containing x*.
  • If |g'(x*)| > 1, iterations spiral or step outward and diverge.
  • Geometrically visualized as a cobweb/staircase diagram bouncing between the iteration curve y = g(x) and the 45° identity line y = x.
Convergence Rate: Linear order (p = 1.0) with asymptotic error constant C = |g'(x*)|.

Jacobi Method (Simultaneous Displacements)

An iterative algorithm for solving square linear systems Ax = b. In each step, every coordinate is updated simultaneously using strictly values from the previous iteration vector.

Component-wise Iteration Formula
xi(k+1) = [ bi − ∑j ≠ i aij xj(k) ] / aii

Matrix Splitting Formulation:

Splitting A = D − L − U into diagonal, strictly lower, and strictly upper parts:

Matrix Iteration Equation
x(k+1) = D−1(L + U)x(k) + D−1b  =  TJ x(k) + cJ
Convergence Guarantee: Guaranteed to converge for any initial guess x(0) if matrix A is strictly diagonally dominant: |aii| > ∑j ≠ i |aij| for all rows i.

Gauss-Seidel Method (Successive Displacements)

Accelerates Jacobi iteration by immediately utilizing the newly updated components xj(k+1) (for j < i) within the current iteration step rather than waiting for the next cycle.

Successive Component Update Formula
xi(k+1) = [ bi − ∑j < i aij xj(k+1) − ∑j > i aij xj(k) ] / aii

Matrix Splitting Formulation:

Splitting A = D − L − U gives the triangular system (D − L)x(k+1) = Ux(k) + b:

Matrix Iteration Equation
x(k+1) = (D − L)−1Ux(k) + (D − L)−1b  =  TGS x(k) + cGS
Convergence Rate: Guaranteed to converge for strictly diagonally dominant or symmetric positive-definite matrices. The spectral radius satisfies ρ(TGS) ≈ [ρ(TJ)]2, converging approximately twice as fast as Jacobi.

The Unified 4-Error Suite

Rigorous error monitoring across both 1D root-finding and multi-variable linear systems:

1. Relative Approximate Error (εa)

εa = | (xnew − xold) / xnew | × 100%

Primary Stopping Rule: Iterations terminate as soon as εa ≤ tol. For vector systems: εa,max = maxi | (xi(k) − xi(k−1)) / xi(k) | × 100%.

2. Absolute Approximate Error (Ea)

Ea = | xnew − xold |

Quantifies raw displacement between successive steps along the coordinate axis. For vectors: Δx = || x(k) − x(k−1) ||∞.

3. Absolute Exact Error (Et)

Et = | xtrue − xapprox |

Theoretical benchmark computed when analytical or high-precision true root is provided.

4. Relative Exact Error (εt)

εt = | (xtrue − xapprox) / xtrue | × 100%

True percentage deviation from the ground truth answer.
